# Sol fidelity prompt rationale

The template separates two authorities: the sketch owns structure and the spell owns appearance. It names concrete geometric invariants—including counts, silhouettes, overlaps, depth order, and negative space—to prevent a visually appealing replacement scene from passing as a faithful render.

It also avoids demanding a literal trace. Rough marks are resolved into finished volumes and surfaces, while ambiguity is handled with a least-change rule grounded in nearby evidence and perspective. That makes the same prompt usable for organic poses, architecture, landscapes, and object layouts without inventing a domain-specific interpretation.
