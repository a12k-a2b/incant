# Incant verification contract

Failures registered before judging/deployment: blank input must not trigger generation; network/invalid JSON must settle; a cancelled/superseded request must not replace the page; microphone release before readiness must stop any late-granted stream; final speech must replace stale typed words; original sketch must remain after failed and successful casts; resize must retain geometry; invalid unauthenticated calls must not use provider keys; room cookies must reject tampering; local keys must be absent from repository and frontend bundle; offline reload must preserve draft after install.

Synthetic browser checks are separate from live provider checks. The live source is a synthetic cottage sketch and synthesized neutral speech, not a real owner drawing or voice recording. The first synthesized audio fixture was empty; its lack of transcript was a HARNESS failure. The corrected nonempty fixture is the successful live voice check.

Remaining device release gates are BLOCKED: actual DC-1 browser/version, installed PWA behavior, physical pen-to-pixel latency, palm/eraser behavior on Wacom, suspend/wake, power/thermal, accessibility traversal on device, and production sustained usage. The Android export is not built or promoted in this PWA-first pass.
