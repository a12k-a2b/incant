# Incant loose ends

## Continue a cast’s style — deferred, 2026-09-11

Owner request: retain the visual style that emerges in a successful cast and optionally carry it into future casts made from new sketches. Track this idea only; do not implement it yet.

The intended experience is choosing a result and asking to “continue this style.” Subsequent drawings still determine their own composition, positioning, proportions, and core elements, while their rendered images share the chosen result’s visual language—linework, palette, shading, texture, and degree of stylization. Carry over the style without inadvertently copying the previous scene or layout. The user should be able to stop or change the chosen style.

This could turn separate sketches and casts into a consistent comic, illustrated story, children’s book, or other work spanning multiple images. A future design could attach the chosen style reference to a story or collection so it survives starting a new parchment and returning later. Character identity continuity is related but distinct; determine separately whether and how it should carry across scenes.

Before building, explore using the selected generation as a visual reference alongside the new sketch and spoken or typed spell. Judge success across several different sketches: recognizable style continuity, faithful new compositions, and no unwanted reuse of prior scene content. The interaction should remain part of Incant’s immersive illustrated world.

## Parchment corner — clarified and implemented, 2026-09-11

The earlier proposal was to peel back a finished image and compare it with its source sketch, not start a fresh page. The owner resurfaced the original proposal and explicitly requested implementation. This supersedes the earlier deferral based on an incorrect interpretation.

The corner now reveals the exact source retained with the selected generation. Drag for a partial comparison or tap for a full toggle. It does not erase ink, alter a generation, or start a page. The moon remains the new-page interaction.
